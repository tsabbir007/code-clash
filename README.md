# CodeClash

CodeClash is a full-stack online judge platform inspired by competitive programming sites like LeetCode and Codeforces.  
It allows users to solve programming challenges, get real-time feedback, participate in contests, and track their performance.  
The platform is designed for individuals, educational institutions, and training organizations to enhance coding skills.

---

## 🚀 Features

- User authentication and profile management
- Problem library with filtering by difficulty and tags
- Built-in code editor with syntax highlighting
- Real-time code execution via self-hosted Judge0 engine
- Submission verdicts (AC, WA, TLE, RE, etc.)
- Contest system with live, dynamic leaderboards
- Submission history and detailed statistics
- Admin panel for problem and contest management
- Responsive design for desktop and mobile
